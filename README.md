# rotex-labs/.github

Organization-wide files for [rotex-labs](https://github.com/rotex-labs).

- `profile/README.md` is the org landing page shown on github.com/rotex-labs.
- `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`, `PULL_REQUEST_TEMPLATE.md` and `ISSUE_TEMPLATE/` are the default community health files for every repo in the org that does not have its own.
- `workflow-templates/` holds the Rust CI starter offered under each repo's **Actions → New workflow**.
- `labels.yml` is the shared label set (apply with a label-sync action or `gh label`).

Brand assets live in [rotex-assets](https://github.com/rotex-labs/rotex-assets).
