# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report them privately through GitHub: open the affected repository, go to **Security → Report a vulnerability**, and fill in the form. This uses GitHub private vulnerability reporting, so only maintainers can see it.

## What to expect

We aim to acknowledge reports within 7 days and to agree a fix and disclosure timeline with you. Credit is given in the advisory unless you ask otherwise.

## Supported versions

Rotex is pre-1.0. Only the latest published version of each crate receives security fixes.
