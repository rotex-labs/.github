# Getting help

- **Questions and ideas:** use GitHub Discussions on the relevant repository, if enabled, or open an issue labelled `question`.
- **Bugs:** open an issue with the **Bug report** form.
- **Feature or capability requests:** use the **Feature request** or **Backend capability** forms.
- **Security problems:** see [SECURITY.md](SECURITY.md); do not file them publicly.

Rotex is maintained by a small team, so replies can take a few days.
